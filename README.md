# وكلاْء محتوى تيك توك — نسخة محلية مجانية

نموذج أولي يعمل على جهازك دون اشتراكات مدفوعة أو مفاتيح API. يحتوي مسارين: محتوى للحملات ومحتوى عضوي بلا حملات، مع وكيل أفكار، وكيل كتابة، مراجعة آلية، لوحة أداء، وتسجيل المشاهدات.

> **مهم:** هذا المشروع لا يتصل بتيك توك ولا ينشر تلقائياً. النشر التلقائي يتطلب تطبيقاً وتفويضاً وموافقة عبر واجهة تيك توك الرسمية. لا تدخل كلمة مرور تيك توك هنا. المراجعة الآلية ليست ضماناً لاكتشاف كل مخالفة، لذلك تحقق من الفيديو بنفسك قبل نشره. لا يمكن ضمان أن كل فيديو سيحصل على مشاهدات أكثر من السابق أو يصبح فيروسياً.

## التشغيل

يتطلب Python 3.10+ فقط:

```bash
python app.py
```

ثم افتح http://127.0.0.1:8000

تُحفظ البيانات محلياً في `data.db`. أوقف الخادم بـ Ctrl+C. لا تفتح المنفذ للإنترنت ولا تضع بيانات حساسة فيه.

## اختيار نموذج محلي (اختياري)

يمكن استخدام Ollama محلياً دون خدمة سحابية مدفوعة. ثبّت Ollama وحمّل نموذجاً، مثلاً `ollama pull qwen2.5:3b`، ثم شغّل الخادم هكذا:

```bash
OLLAMA_MODEL=qwen2.5:3b python app.py
```

إذا لم يكن Ollama متاحاً، يستخدم النظام قالباً محلياً بسيطاً لكتابة المسودة. لا يتصل المشروع بخدمات AI خارج جهازك.

## سير العمل

1. أدخل فكرة/موضوعاً أو ترنداً رصدته بنفسك، وحدد هل هي حملة أم عضوية.
2. النظام يرتب الفكرة بشكل إرشادي ويكتب مسودة قصيرة.
3. وكيل المراجعة يفحص النص آلياً بحثاً عن مؤشرات مخالفة. الفحص محدود وليس فتوى أو حكماً نهائياً، ولا يستطيع إثبات عدم ظهور نساء في ملف فيديو.
4. سجّل المشاهدات لاحقاً لمقارنة النتائج وتحسين الأفكار التالية.

لا يقوم النظام بجلب الترندات من تيك توك أو كشط الموقع، ولا ينشئ روابط حملات أو ينشر محتوى نيابة عنك في هذه النسخة.

## واجهات محلية

- `GET /api/dashboard` — ملخص الأداء.
- `GET /api/videos` — قائمة الفيديوهات.
- `POST /api/ideas` — إنشاء فكرة: `{"topic":"لغز منطقي","track":"organic"}` أو `track: "campaign"`.
- `POST /api/videos/{id}/generate` — توليد السيناريو.
- `POST /api/videos/{id}/review` — تشغيل المراجعة الآلية.
- `POST /api/videos/{id}/views` — تسجيل المشاهدات: `{"views":123}`.
